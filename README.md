# مولد جلسات تيليجرام

أداة بسيطة لإنشاء جلسات Pyrogram لحسابات تيليجرام.

## المتطلبات
- Python 3.7 أو أحدث
- حساب تيليجرام مفعل
- API ID و API Hash من [my.telegram.org](https://my.telegram.org)

cd telegram-session-generator


تثبيت المكتبات:

bash
